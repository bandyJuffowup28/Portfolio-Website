8-bit Breadboard CPU

This is currently a work in progress. Once complete this 8-bit breadboard computer will be turing complete. It will have conditional branching, unconditional braching, load immediate instructions, data transfer, ALU ops, and stack operations. Some parts are Ben Eater inspired/copied such as the cpu clock and pc counter(however they are not 1-1). Fully custom ALU with 16 ops, 4 registers, mixed Von Neumann and Harvard architecture, 8-bit instructions, 30+ control signals, 4 eeproms for the control signals, separate code and data memory, fully custom instruction set with 60+ instructions, dozens of logic ICs, over 100 resistors, over 100 leds, dc-dc buck converter for power supply(5V), debounced buttons, over 1000 wires, programmed eeproms using a microcontroller and arduino ide(the hardware is ben eater inspired but the code for programming the eeproms is vastly different), hundreds of unique microcode instructions for the 60+ instructions.
